Ako nastaviť prístup v Microsoft 365
  1. Entra ID → App registrations → New registration (single tenant).
  2. API permissions → Microsoft Graph → Application → Mail.ReadWrite (stačí Mail.Read, ak nepresúvate/neoznačujete) → Grant admin consent.
  3. Certificates & secrets → nový client secret alebo certifikát.
  4. Obmedzte prístup len na DMARC schránku (Exchange Online PowerShell – RBAC for Applications): 
    New-ServicePrincipal -AppId <ClientId> -ObjectId <EnterpriseAppObjectId> -DisplayName "DMARCula"
New-ManagementScope -Name "DMARCula" -RecipientRestrictionFilter "PrimarySmtpAddress -eq 'dmarc@contoso.com'"
New-ManagementRoleAssignment -App <ClientId> -Role "Application Mail.ReadWrite" -CustomResourceScope "DMARCula"
    Pri RBAC for Applications odstráňte Graph povolenie Mail.ReadWrite z App registration (inak platí pre celý tenant).
